How it works
1
Drop your files
Select any files from your device. Nothing is uploaded yet — files stay local.
2
Share the code or link
A unique 8-character room code is generated. Send it to your receiver via any channel.
3
P2P connection forms
Our FastAPI signaling server brokers a WebRTC handshake, then steps aside. Data flows peer-to-peer.
4
Files arrive instantly
The receiver's browser downloads directly from yours. No cloud, no waiting, no account.
