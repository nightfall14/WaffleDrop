The Basics: Colors, Backgrounds, Borders, Margins, Padding, Height/Width.

CSS Box Model: (CRITICAL) You must understand how padding, borders, and margins affect the size of a box.

CSS Box Sizing: (CRITICAL) Always set box-sizing: border-box;. It makes the Box Model actually make mathematical sense.

CSS Display: Know the difference between block, inline, and none.

CSS Position: relative, absolute, and fixed. (You will use this for your Drag-and-Drop zone).

CSS Pseudo-classes: Specifically :hover, :focus, and :active (for styling buttons and file links).

CSS Units: Know px, rem, vh, vw, and %.

CSS Flexbox (ALL OF IT): This is the most important topic on the entire list. It is how you align items in a row or column.

CSS Responsive (Media Queries): How to make your app look good on a mobile phone.

CSS Variables: (e.g., var(--primary-color)). This makes changing your app's color theme incredibly easy.

🥈 Tier 2: Good for Polish (Learn when you need it)
These make your app look modern and professional, but you don't need to memorize them. Just know they exist so you can Google them later.

CSS Grid: Great for full-page layouts, but Flexbox can handle almost everything if you are just starting.

CSS Rounded Corners: (border-radius) Makes buttons and cards look modern.

CSS Shadows: (box-shadow) Adds depth to your file cards.

CSS Transitions: (e.g., transition: all 0.2s;) Makes hover effects fade in smoothly instead of snapping instantly.

CSS object-fit: Great for making user profile pictures fit perfectly inside a circle.
